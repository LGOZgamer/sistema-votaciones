Sistema de Votaciones - PHP + MySQL

Ruta recomendada:
C:\xampp\htdocs\sistema_votaciones

URL:
http://localhost/sistema_votaciones/login.php

Instalación:
1. Copia la carpeta sistema_votaciones dentro de C:\xampp\htdocs.
2. Abre phpMyAdmin.
3. Importa el archivo db.sql.
